## 🚀 Proje Detayları ve Geliştirilen Özellikler

Mevcut iskelet yapı (codebase) tamamen özelleştirilmiş ve işletme ihtiyaçlarına göre şu modüller projeye entegre edilmiştir:

* **Etkileşimli Hero Alanı:** Kullanıcıyı karşılayan yüksek kaliteli arka plan ve doğrudan "Masa Ayırt" (Call-to-Action) yönlendirmesi içeren giriş bölümü.
* **Akıcı Yönlendirme (Smooth Scroll):** Üst menü navigasyonunda (Hakkımızda, Menü, Rezervasyon, İletişim) sayfa içi akıcı kaydırma (smooth behavior) uygulanmıştır.
* **Genişletilmiş İçerik Yönetimi:** "Hikayemiz ve Tarihçemiz" ile "Şefin Haftalık Önerisi" bölümleri tipografik hiyerarşiye uygun olarak sıfırdan tasarlanmıştır.
* **Dinamik Ürün Kartları (Grid Layout):** "Öne Çıkan Menümüz" bölümünde, yemek görselleri, içerik açıklamaları ve fiyatlandırmaların yer aldığı 3 sütunlu, hover (üzerine gelme) animasyonlarına sahip modern kart yapıları kullanılmıştır.
* **Kapsamlı Rezervasyon Modülü:** Kullanıcıların tarih, kişi sayısı ve promosyon kodu gibi detayları girebileceği özel form alanı tasarlanmış; UI kontrastını dengelemek adına yan paneline "Çalışma Saatleri" ve "İletişim" kartları yerleştirilmiştir.
* **Responsive Optimizasyon:** Mobil cihazlarda tasarımın bütünlüğünü korumak adına tüm bileşenler (menü, formlar, ürün kartları) CSS Media Queries ve Bootstrap Grid sistemi ile optimize edilmiştir.

## 🛠️ Kullanılan Teknolojiler
* **HTML5:** Semantik web standartları.
* **CSS3:** Özel stil tanımlamaları (`index.css`), hover animasyonları.
* **Bootstrap 4:** Temel grid (ızgara) iskeleti ve responsiv yapı.
* **JavaScript:** Menü içi etkileşimler ve smooth scroll özellikleri.

## 💻 Kurulum (Lokalde Çalıştırma)
Projeyi kendi bilgisayarınızda çalıştırmak için:
1. Repoyu bilgisayarınıza klonlayın: `git clone https://github.com/Yusufobenay/Restaurant-Website.git`
2. Klasörü VS Code gibi bir kod editörü ile açın.
3. `index.html` dosyasını tarayıcıda veya Live Server eklentisiyle çalıştırın.
